# 항공사 도장 텍스처 (World Flight Simulator)

게임의 흰색 비행기 모델(도장용 UV)에 맞춰 다시 구운 도장 이미지입니다.

## 출처와 라이선스

| 폴더 | 원본 | 라이선스 |
|---|---|---|
| `A320CEO/` (DLH, BAW, AFR) | FlightGear A320-family 도장 (`Models/Liveries/A320-*.png`), https://github.com/FGMEMBERS/A320-family | GNU GPL v2 (`COPYING-GPLv2.txt`) |

- 원본 텍스처를 FlightGear A320 모델에 입힌 뒤, 그 겉모습을 우리 모델 표면으로 옮겨 구웠습니다 (`tools/blender/bake_livery.py`, `composite_livery.py`).
- 이 폴더의 이미지는 원본과 같은 GNU GPL v2 조건으로 배포합니다.
- 항공사 이름과 로고는 각 항공사의 상표입니다. 이 게임은 항공사와 관계가 없습니다.
